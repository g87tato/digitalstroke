# Investigación de palabras clave (Google Ads Keyword Planner)

Fecha: 2026-10-07 · País: España · Idioma: español · Periodo: sept 2025 – ago 2026
Cuenta usada: sin campañas activas → Google solo da **rangos** de volumen (no cifras exactas). Pujas = intervalo de la parte superior de la página (CPC orientativo).

## Hallazgo clave
Las búsquedas que describen NUESTRA oferta tienen volumen casi nulo (0–10/mes):
`página web para autónomos`, `diseño web autónomos`, `web barata para autónomos`, `página web en 5 días`.
Lo que SÍ se busca es **precio/coste**: la gente quiere saber cuánto cuesta. Nuestro precio cerrado de 900 € es justo la respuesta.

## Cola larga (10–100/mes, pujas bajas, más fáciles de posicionar)
cuanto cuesta tener una pagina web (0,78–1,89) · cuanto cobran por hacer una pagina web (0,82–1,94) ·
cuanto cuesta que te hagan una pagina web (1,12–2,54) · cuanto cuesta diseñar una pagina web (0,82–2,49) ·
hacer pagina web precio (0,87–3,12) · crear pagina web precio (1,35–3,92) · landing page precio (1,47–6,87)

## Descartar
- `presupuesto pagina web`: puja alta (hasta 7,88 €) y caída −90 %.
- Términos con "República Dominicana", "Estados Unidos", "wordpress": fuera de mercado.
- `cuanto cuesta posicionarse en google`: puja hasta 20 €, otro servicio.

## Decisiones para la web
1. Añadir una sección/pagina **"¿Cuánto cuesta una página web en 2026?"** con el 900 € como ancla (SEO + Ads).
2. Título H1/H2 de la home y una landing de Ads alineados con "precio página web" + "cuánto cuesta".
3. Campaña de búsqueda: concordancia exacta/frase con los 9 términos de la tabla; 10–15 €/día.
4. Negativas iniciales: gratis, wordpress, wix, curso, tutorial, empleo, república dominicana, estados unidos.
5. Pendiente: con la campaña activa, Google dará volúmenes exactos y se afina la lista.

## Limitaciones
Rangos en lugar de cifras; solo se revisaron las ~40 primeras de 314 ideas. Falta explorar nichos por oficio (fontanero, abogado, psicólogo…) y ciudades.

## Segunda ronda: nichos por oficio (2026-10-07)
Semillas: "web para clínica / abogados / restaurante / peluquería / fontanero / psicólogo", "página web para dentista, electricista, fisioterapeuta, arquitecto, taller mecánico".
- Resultado: casi todas **0–10 búsquedas/mes** y Google las descartó por demasiado específicas. Solo una salió con 100–1k (variante "web restaurante").
- Conclusión: **no hay demanda medible de "página web para [oficio]"**. No merece la pena una landing por oficio para SEO (sí para confianza/conversión en tráfico directo).
- Términos genéricos que sí tienen volumen: `landing page` (1k–10k, informativa, puja 1,30–5,25 €), `página web profesional` (100–1k), `crear página web profesional` (100–1k).
- Ruido a evitar: "landingi", "leadpage" (marcas de software), "ropa barata online" (otro sector).
