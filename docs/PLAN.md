# digitalstroke.es — Plan de arranque

## Oferta
Web o landing para autónomos y pymes · 900 € + IVA · 3–5 días.

## Estrategia SEO (mercado competitivo → long tail)
No competir por "diseño web" (dificultad altísima). Atacar intención concreta + local + nicho.

**Hipótesis de palabras clave (PENDIENTE validar con Planificador de Google Ads: volumen, CPC, competencia):**
- Precio cerrado: "página web 900 euros", "cuánto cuesta una web para autónomos", "web barata para autónomos"
- Urgencia: "página web en 5 días", "landing page rápida", "crear web en 48 horas"
- Nicho: "página web para fontaneros / electricistas / psicólogos / abogados / peluquerías / clínicas" (una landing por oficio)
- Local: "diseño web autónomos [ciudad]", "diseñador web freelance [ciudad]"

**Arquitectura web:** home → /servicios/landing, /servicios/web-pymes → /para/[oficio] (programáticas) → /blog (guías de precio y "cómo conseguir clientes con tu web").

## Google Ads (fase de validación, 2–4 semanas)
- Campaña Búsqueda, concordancia exacta/frase, presupuesto 10–15 €/día.
- Objetivo: conversiones (formulario + clic WhatsApp). Usar los términos que conviertan para decidir qué posicionar en SEO orgánico.
- Lista de negativas desde el día 1 (gratis, plantilla, curso, wordpress tutorial, empleo).

## Automatizar vs. supervisar
| Proceso | Automático | Supervisión humana |
|---|---|---|
| Captura de leads (formulario→email/CRM) | ✅ | Revisión diaria |
| Respuesta inicial por WhatsApp/email | ✅ plantilla | Personalizar antes de enviar presupuesto |
| Informes semanales Ads/Analytics | ✅ | Revisión semanal |
| Alertas web caída / formulario roto | ✅ | Actuar si salta |
| Pujas y presupuesto Ads | Reglas básicas | **Semanal**: negativas, anuncios, CPA |
| Facturación y recordatorios de cobro | ✅ | Mensual |
| Esqueleto de web (plantilla propia) | ✅ | **Siempre**: diseño y copy por proyecto |
| Contenido de blog | Borrador asistido | **Siempre**: edición y verificación |
| Precio, alcance y llamadas de brief | ❌ | Humano |
| Cumplimiento legal (RGPD, cookies, aviso legal) | Plantilla | Revisión por cliente |
